THE DECISION PROBLEM

Location intelligence without pretending to predict the future.

Commercial location decisions are expensive, but enterprise-grade location intelligence can be inaccessible to smaller operators. Our prototype asked a narrower and more defensible question: can open POI data create comparable signals that help a user shortlist areas before doing deeper due diligence?

We deliberately framed the result as decision support, not revenue prediction. The user should be able to trace the score back to visible evidence.

02

SPATIAL INTELLIGENCE

Build the geography so the model can be compared and explained.

The core pipeline used Python and Polars to process open POI data, H3 cells as a scalable geographic unit, and transparent score components for competition, complementary activity, data quality and — where available — contextual layers such as transit and market proxies.

03

EXPLAINABILITY & RELIABILITY

Make the evidence survive the demo.

We separated the deterministic score and narrative from optional LLM enrichment. That meant the core recommendation remained available even if an API quota or network call failed. The interface exposed the score components so a judge or user could see what moved the ranking instead of receiving one opaque number.

The strongest product lesson was simple: trust improves when the path inputs → components → final score stays visible.
04

LEADERSHIP

Connect the technical pieces to one argument.

As team lead for spatial intelligence, my job was not only to implement geospatial components. I also had to keep the problem statement, scoring logic, map and pitch aligned. The project strengthened a leadership style I value in research teams too: make assumptions visible, keep interfaces between workstreams clear, and ensure the final claim is no stronger than the evidence supporting it.

WHAT CHANGED

From optimising a metric to designing an interpretable decision.

Expansion Copilot shifted my attention from “what model scores highest?” toward “what information should the system expose so another person can reason with it?” That question now influences how I think about evaluation, reasoning systems and human-facing AI more broadly.
