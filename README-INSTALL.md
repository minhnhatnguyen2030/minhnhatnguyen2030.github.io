# Datathon Story 2025 — Website Drop-in

This folder creates a standalone story page for the SUDATA × SUBAA Datathon journey from 2024 to 2025.

## Recommended upload location

Place the entire folder in the ROOT of your GitHub Pages repository:

    /datathon-story-2025/
        index.html
        datathon-story.css
        /assets/
            datathon-2024-group.jpg
            datathon-2025-team-anime.jpg
            datathon-2025-certificate.jpg

Then the page will be available at:

    https://<your-github-username>.github.io/datathon-story-2025/

## Link it from Awards & Scholarships

Open `awards-entry-snippet.html`.

Copy the award row into the Awards & Scholarships section of your homepage.

If your existing awards section uses different HTML class names, keep the text/link but use your existing row markup.

Suggested visible entry:

    2025  |  1st Place — SUDATA × SUBAA Datathon 2025
              Team Clesmor · Supply-chain forecasting & optimisation
